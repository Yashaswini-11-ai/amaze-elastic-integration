# MirrorMire AMaze Elastic Integration

A native [Elastic Integration](https://www.elastic.co/integrations) package that
collects detection alerts, network security logs, and audit events from the
MirrorMire AMaze deception platform with Elastic Agent.

## Data streams

| Data stream | Source API | Description |
|-------------|------------|-------------|
| `alerts` | `GET /api/v3/tickets` | Actionable incident tickets (detections) generated by AMaze |
| `logs` | `GET /api/v3/external/logs` | External-network SCA detection logs |
| `audit` | `GET /api/v3/audit-log` | Immutable audit trail of administrative actions |

Each data stream polls the AMaze REST API on a configurable interval, splits
the response into individual events, normalizes the fields into ECS, and
indexes them into Elasticsearch. Original AMaze values are preserved under the
`amaze.*` namespace so no data is lost during transformation.

See [package/docs/README.md](package/docs/README.md) for setup, ECS mapping,
and troubleshooting.

## Requirements

- Elastic Stack 8.x with Elastic Agent and Fleet
- A MirrorMire AMaze deployment exposing the REST API v3 (`/api/v3`)
- A bearer token (JWT or API token) with read permission on the resources above

## Build and validate

The package is validated with [elastic-package](https://github.com/elastic/elastic-package):

```bash
cd package
elastic-package lint    # static validation
elastic-package build   # produces build/packages/amaze-<version>.zip
elastic-package test    # end-to-end tests against a live stack (requires Docker)
```

## Goal

Enable AMaze to become a native Elastic integration that can eventually be
published through the Elastic Package Registry and installed from the Kibana
Integrations Catalog.
